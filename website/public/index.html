Meet Laya

Small model.
Sense of direction.

Laya is the local decision model at the heart of the plan. It classifies your request and picks among options, then Routey matches those choices to the models you’ve configured.

On supported Macs, Laya runs through Core ML on the Apple Neural Engine. If it’s unavailable, a heuristic fallback keeps routing moving and tells you what happened.

The routing decision is local. The selected agent may use a hosted provider, depending on your model roster.

A few things
before we set off.

Is this a new agent?

Routey is a desktop built on the pi framework and forked from pi-gui. Pi provides the agent runtime; Routey adds a simpler interface and a routing layer.

Can I use my own models?

The plan includes a configurable roster with local, hosted, and frontier tiers. Routey chooses from the models that are available and authenticated in your setup.

Does everything run locally?

The Laya routing model runs locally on supported Macs. The agent itself can run through a local or hosted model. Your chosen provider determines where that agent request goes.

Can I download it yet?

This page introduces the project and its first milestone. A Routey download and guided onboarding aren’t offered here yet. The roadmap above shows where we’re headed.
