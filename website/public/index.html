Meet Laya, head of brain allocation

A tiny model
with a clipboard.

Yes, we hired a model to pick the models. Laya runs locally, sizes up your request, and chooses a tier, thinking level, and mode. Routey matches that to an available model in your roster. You remain blissfully uninvolved in the staffing decision.

Laya runs on the Apple Neural Engine on supported Macs. If it’s unavailable, a rule-based fallback takes the clipboard. The Inspector tells you who’s on duty.

Reasonable questions.
Dubious branding.

Do I have to pick a model every time?

That’s the whole thing: no. Configure your model roster, then just ask. Routey picks from your available local, hosted, and frontier models for each turn. Your new job title is “person with a task.”

Can my laptop’s model hang out with the fancy ones?

Absolutely. Local and frontier models belong in the same roster and can take turns in the same chat. Routey chooses one available, authenticated model per turn. Having several work on the same task at once is a later phase. Tiny velvet rope, for now.

Does everything run locally?

The Laya routing model runs locally on supported Macs. The agent itself can run through a local or hosted model. A frontier route sends the agent request to that provider. The cloud is still the cloud, even when a duck does the admin.

Can I download it yet?

We’re still assembling the duck. This page introduces the project and its first milestone; downloads and guided onboarding aren’t offered here yet.

Who approved this name?

There was insufficient adult supervision. Routey McRouteface is built on the pi framework and forked from pi-gui. The agent runtime has a respectable pedigree. The name has a little hat on.
